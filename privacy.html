プライバシーポリシー

「ローカルメール仕分け」（以下「本アプリ」）は、個人が自分のパソコンで自分の Gmail を仕分けるために使うものです。本アプリは配布しておらず、利用者は開発者本人のみです。

1. 取得する情報

本アプリは Gmail API を通じて、利用者自身のメールの差出人・件名・受信日時・本文を読み取ります。添付ファイルの中身は読み取りません。

2. 利用目的

  • メールを「重要」「広告」などに分類し、利用者自身の Slack チャンネルへ差出人・件名・短い要約を届けること。
  • 届け終えたメールの未読ラベルを外すこと。

メールの送信・削除・移動・転送は行いません。

3. 処理の場所と第三者への提供

分類はすべて利用者のパソコン内で動くAI（Ollama）で行い、メールの内容をインターネット上のAIサービスやその他の第三者に送ることはありません。Slack へ送るのは差出人・件名・短い要約だけで、本文は送りません。

4. 保存と保護

取得したメールの内容と分類結果は、利用者のパソコン内に Windows のユーザー単位で暗号化して保存し、既定で 7 日後に削除します。Google の認証情報も同様に暗号化して保存します。

5. Google API の利用

本アプリによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 権限の取り消し

利用者はいつでも Google アカウントのアクセス権の管理から本アプリの権限を取り消せます。
